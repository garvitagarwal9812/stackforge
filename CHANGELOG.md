# Changelog

All notable changes to StackForge will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-09-15

### Added
- Interactive terminal wizard with step-by-step project configuration
- Rich TUI with cyberpunk, matrix, and nord color themes
- **Backend templates**: FastAPI, Express.js (TS), NestJS, Go (Gin), Rust (Axum), Django, Spring Boot
- **Frontend templates**: React 18 + Vite, Next.js 14/15, Vue 3 + Vite, SvelteKit 2
- **Database support**: PostgreSQL 16, MongoDB 7.0, Redis 7.2, SQLite 3, MySQL 8.0
- **CI/CD pipelines**: GitHub Actions, GitLab CI/CD, Azure DevOps, Jenkinsfile, CircleCI
- **DevOps infrastructure**: Docker, Docker Compose (dev/prod), Kubernetes manifests, Helm Charts, Terraform IaC
- **Monitoring**: Prometheus & Grafana configuration templates
- Curated architecture presets (FastAPI Cloud, MERN, PERN, Go High-Throughput, Rust Axum, Next.js Enterprise, Spring Boot)
- Auto-generated Makefile with common development commands
- Live syntax-highlighted file previewer in terminal
- ASCII directory tree generator
- Config import/export via `.stackforge.json` files
- Dry-run simulation mode with `--dry-run` flag
- Headless CLI mode with full flag support for scripting
- Published as both `pip` (PyPI) and `npm` (npmjs) packages
- Comprehensive unit test suite
